# Selah — one moment before send

Competition project: https://github.com/numaritaisei-commits/selah-one-moment

Selah is a local simulated composer demonstrating an optional eight-second pause before a social-media reply would be sent. It does not connect to a social network, censor, rewrite, or post for the user. Gloo AI chooses one validated passage reference and one server-authored reflection question; YouVersion supplies the exact verse text, translation, and attribution.

The name is inspired by the recurring Scriptural word *Selah*. This project does not assert a single settled translation of that word.

## What the demo proves

- The user keeps the original draft and chooses whether to pause.
- Gloo output is constrained to an opaque server-side passage allowlist.
- Verse text is never generated by an LLM. Live verse text and attribution come from YouVersion.
- Invalid model output, missing attribution, redirects, oversized responses, and provider failures are rejected.
- A failed pause is fail-open: the user can continue editing or post normally.
- The app writes no draft, provider response, token, or credential to disk.

The app cannot promise that external API providers do not retain submitted data; provider handling is governed by their terms. Use synthetic demo text only.

## Run the safe offline preview

Requires Python 3.11+ and no third-party packages.

```bash
python3 server.py
```

Open `http://127.0.0.1:8765`. Offline preview never calls either provider and intentionally displays no Bible text.

## Run tests

```bash
python3 -m unittest discover -s tests -v
```

## Live competition demo

Live mode is deliberately gated. Before using it, confirm that the Scripture in New Frontiers participant entitlement is active, that Gloo requires no card or payment, and that the selected YouVersion Bible is licensed to the app.

```bash
python3 server.py --live --confirm-zero-cost --bible-id <LICENSED_BIBLE_ID> --gloo-model <VERIFIED_ZERO_COST_MODEL>
```

Live mode remains code-locked until `APPROVED_ZERO_COST_GLOO_MODELS` is populated from the official participant account after a no-card, zero-cost entitlement check. The process then prompts without echo for the Gloo client ID, Gloo client secret, and YouVersion App Key. Do not put them in `.env`, command arguments, source code, screenshots, notebooks, or recordings. Credentials and OAuth tokens remain in process memory. Each process permits one provider reflection by default.

The live adapter uses only these fixed official endpoints:

- `https://platform.ai.gloo.com/oauth2/token`
- `https://platform.ai.gloo.com/ai/v2/chat/completions`
- `https://api.youversion.com/v1/bibles/{id}`
- `https://api.youversion.com/v1/bibles/{id}/passages/{USFM}`

Official references: [Gloo authentication](https://docs.gloo.com/tutorials/authentication), [Gloo Completions V2](https://docs.gloo.com/api-reference/completions/v2), [YouVersion authentication](https://developers.youversion.com/authentication), and [YouVersion Bible endpoints](https://developers.youversion.com/api/bibles).

## Architecture

```text
synthetic draft + intent
        │
        ▼
Gloo AI: allowlisted passage_key + one question
        │ strict JSON + exact enum validation
        ▼
server-side passage map
        │
        ▼
YouVersion: exact text + reference + version metadata + copyright
        │ required attribution validation
        ▼
local browser display (textContent, no app-side persistence)
```
